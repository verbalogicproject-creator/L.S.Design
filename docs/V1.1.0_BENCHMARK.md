## Automated results

Both production builds passed. Playwright checked 360×800, 768×1024, and 1440×1000 viewports.

- No horizontal overflow at any checked width.
- One `h1`, seven main sections, and two navigation landmarks in each result.
- Graphite/Sand controls update `aria-pressed` correctly.
- The first keyboard stop is the visible-on-focus “Skip to content” link.
- Reduced-motion media queries activate in both results.
- No console error, uncaught page error, or remote asset request was recorded.
- The website retains all content without Canvas or WebGL.
- Forced WebGL failure leaves 2,300 characters of main DOM content, shows the static speaker, hides the failed canvas, and reports the fallback through a live status message.

Headless Chromium in this environment created and then lost its WebGL context, so the normal automated 3D screenshots exercised the context-loss fallback. The TypeScript source and production build verify the real Three.js scene, material, light, on-demand render, resize, visibility, context-loss, and disposal paths. Hardware-GPU visual inspection remains a documented environment limitation, not a hidden pass claim.

## Visual review

Both results replace the previous fluorescent yellow-green treatment with warm paper, graphite, sand, mineral green, and restrained clay focus color. Neither uses glow, bloom, glass, grain, pills, remote fonts, or stock media as a quality shortcut.

The website result uses one waveform study as its principal motif and varies the remaining sections through a product diagram, feature ledger, material triptych, finish workspace, specification table, and quiet purchase close. The 3D result uses the product scene for material inspection, then changes to sound-field geometry, an editorial feature ledger, paired material studies, a synchronized finish selector, specifications, and purchase content.

The language stays within the supplied facts. It explains the compact form, controls, materials, finishes, battery life, price, and room-filling benefit without adding awards, measurements, reviews, technical performance claims, or customer evidence.
