# L.S.Design v1.0.0 — Initial Stable Release

L.S.Design v1.0.0 is the first stable public release of a provider-neutral frontend design skill suite for coding agents.

## What is included

- A router skill for direction and multi-surface work
- Complete website design
- Focused landing-page design
- Responsive web and native mobile design
- Audit-first redesigns
- Design systems and component contracts
- Art direction and controlled visual variety
- Evidence-based frontend review
- Accessible, adaptive 3D web experiences

## 3D and procedural design

The 3D specialist covers product viewers, configurators, spatial stories, technical scenes, and scientific visualizations. It selects among Three.js, React Three Fiber, Plotly, D3/SVG, `model-viewer`, and Spline according to the real task.

The release includes reproducible recipes for parametric point clouds, scalar height fields, quantized comparisons, Voronoi views, and persistence diagrams. It preserves host typography and colors, labels synthetic or illustrative data honestly, and requires accessible controls and stable fallbacks.

## Portable installation

Install both supported provider layouts into the current project:

```sh
python scripts/install.py
```

Install globally:

```sh
python scripts/install.py --scope global
```

The same canonical skill bytes are installed into Codex-compatible and Claude Code directories. Installation is staged, checksum-verified, and refuses unexpected replacement.

## Validation

Version 1.0.0 includes tests for:

- Nine-skill structure and frontmatter
- Shared decision-order presence
- Provider neutrality
- Relative reference integrity
- Hidden Unicode and instruction-like source payloads
- Dry-run and conflict behavior
- Forced replacement
- Checksum equality across provider layouts

## Try the difference

Use the controlled [website versus 3D comparison exercise](https://github.com/verbalogicproject-creator/L.S.Design/blob/v1.0.0/docs/COMPARISON_TEST.md) to run the same product-website brief with `ls-design-websites` and `ls-design-3d-web`.

## Compatibility

- Python 3.9 or newer for repository scripts
- Provider-neutral Markdown skill format
- Project and global layouts for Codex-compatible agents and Claude Code
